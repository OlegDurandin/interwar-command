# CLAUDE.md — совместимость с Claude Code

**Комплект:** 1.1 · **Дата:** 18.11.2026.

Основные постоянные инструкции находятся в `AGENTS.md`. Прочитай их и следуй им. Единственный нормативный источник требований игры — `SPEC.md` в корне. Читай разделы и документы, относящиеся к текущему поручению.

Текущий этап определяет пользователь. `FIRST_TASK.md` описывает только первый запуск и применяется, когда он явно поручен. Не перезапускай разработку с него при каждой новой сессии. Проверяй состояние кода и `PROGRESS.md`, сохраняя существующую работу.

Выполни весь порученный объём, включая проверки и исправления, без промежуточных остановок для обычных локальных действий. Заверши на границе поручения или сообщи о конкретном блокере. Формат отчёта и архитектурные границы — в `AGENTS.md`.

Этот файл — короткий указатель для совместимости. Не дублируй здесь SPEC или отдельный набор правил. Для запуска через Codex этот файл не требуется.
