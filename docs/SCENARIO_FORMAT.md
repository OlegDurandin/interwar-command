# Формат сценария v1

Файл содержит один JSON-объект UTF-8 размером до 16 МиБ (16 777 216 байт). Версии для этого загрузчика — `schema_version: 1` и `rules_version: "0.1"`. Требования описаны в [SPEC §12.2](../SPEC.md), поля и допустимые значения — в [JSON Schema Draft-07](../content/schemas/scenario-v1.schema.json). Полный пример — [учебная «Переправа»](../content/scenarios/crossing.json).

## Проверка файла

Из корня репозитория выполните:

```sh
cargo run --locked -p game-core --example validate_scenario -- content/scenarios/crossing.json
```

Успешный запуск выводит сводку и завершает процесс с кодом 0. Ошибка даёт ненулевой код. Для использования из Rust передайте содержимое файла в `game_core::scenario::load_scenario(&bytes)`. Результат — нормализованный `Scenario` с массивом `warnings` или `ScenarioError` с кодом, путём к входному полю и сообщением. Например, `units[1].q` указывает на координату второй записи до сортировки.

## Поля документа

| Поля | Формат |
|---|---|
| `id`, `title`, `historicity` | ID сценария, название, одна из строк `fictional`, `inspired`, `historical` |
| `turn_days`, `random_seed` | Целое положительное число дней и десятичная строка от `"0"` до `"18446744073709551615"`. У seed запрещены знак, пробелы и ведущие нули |
| `factions`, `starting_faction_id` | Ровно две записи с `id` и `name`. Инициатива задаётся ссылкой по ID |
| `map` | Встроенная карта с размерами, `default_terrain` и `default_controller` (ID или `null`). Массивы `tiles` и `edges` по умолчанию пусты |
| `units` | До 2048 частей. Для каждой нужны ID, фракция, тип, `q`, `r`, `strength` 1–10, `readiness` 0–100 и `entrenchment` 0–2. Метаданные `name`, `historical_id` — строки, `experience` — целое неотрицательное число в диапазоне u32 |
| `objectives`, `victory` | 1–256 целей типа `control`. У каждой есть ID, координаты и `points_per_round` 1–1000. `max_rounds` — 1–10000. Поле `target_score` можно опустить или задать положительным u32 |

Четыре допустимых типа частей — `infantry`, `cavalry`, `artillery`, `headquarters`. Поля текущего хода и рассчитанного снабжения не входят во входной документ. Неизвестное поле или значение перечисления даёт ошибку.

## Нормализация и связи

- Карта содержит от 1 до 256 клеток по каждой оси, всего до 16 384. Размеры и координаты задаются целыми числами. Клетки находятся в пределах `0 <= q < width`, `0 <= r < height`.
- Переопределение клетки содержит `q` и `r`. При отсутствии `terrain` или `controller` наследуется значение карты. Явный `controller: null` задаёт нейтральную клетку. По умолчанию `city_id` равен `null`, `supply_source` равен `false`. Повторно указать ту же клетку нельзя.
- Ребро задаётся концами `a` и `b` в формате `[q, r]`. Концы должны быть соседними сухопутными клетками. Пропущенные флаги `river`, `bridge`, `road`, `rail` равны `false`. Для моста обязательна река. Запись с переставленными концами обозначает то же ребро.
- ID сценарных объектов содержат 1–64 символа и уникальны в пределах своего типа. Ссылки на фракции должны разрешаться. Части стоят на суше под контролем своей фракции, по одной на клетку. Цели стоят на суше, по одной на клетку. У каждой фракции есть хотя бы один контролируемый сухопутный источник.
- Загрузчик проверяет связи и границы карты после структурного разбора. Он возвращает фракции, части и цели в порядке ID. Клетки и рёбра нормализует `Map::new` из T-002.
- Пустой источник под вражеской ZOC даёт предупреждение `BlockedSource`. Дружественный гарнизон снимает блокировку. Штаб противника сам ZOC не создаёт. Если `target_score` превышает сумму очков всех целей за все раунды, загрузка возвращает `UnreachableTarget` с расчётным максимумом.

## Метаданные

Необязательные `description` и `period` — текст, `languages` и `sources` — массивы строк. Для `historical` требуется хотя бы один непустой источник и объект `historical_context`. В v1 этот объект содержит календарную `map_date` в формате YYYY-MM-DD, текстовые `hex_scale` (масштаб с единицей длины), `formation_scale` (размер соединения), `assumptions` (границы допущений) и `review_version` (версия проверки). Вымышленная учебная карта имеет пометку `fictional`.

Для проверки схемы из корня выполните `pnpm install --frozen-lockfile` и `pnpm test:schema`. Межобъектные условия, лимит в байтах и предупреждения проверяет Rust-загрузчик; его тесты запускаются командой `cargo test -p game-core --test scenario`.
