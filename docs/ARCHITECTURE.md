# Каркас первого этапа

`game-core` оперирует axial-координатами `i32`. Расстояние возвращается как `u64`, включая пары крайних значений координат. Каждый из шести слотов `neighbors()` соответствует направлению из SPEC §5.1. За пределами представимого диапазона слот равен `None`. Размер тестового листа ограничивает выбор в renderer.

`game-wasm` экспортирует `hex_distance(q, r, other_q, other_r)`. Функция делегирует вычисление ядру. Сгенерированный wasm-bindgen контракт принимает четыре числа и возвращает `bigint`. UI передаёт целые координаты выбранной клетки и преобразует результат в строку для отображения.

Корневая команда подготавливает `crates/game-wasm/pkg` до запуска Vite или TypeScript. Клиент импортирует сгенерированный ES-модуль. Vite обрабатывает URL бинарного файла относительно модуля и выпускает отдельный ассет. В dev доступ к нему обеспечивает штатная граница pnpm workspace.

React ожидает общий Promise инициализации WASM перед запуском карты. После асинхронной подготовки WebGL приложение PixiJS рисует лист и выделение. Обработчики указателя и ResizeObserver работают в координатах canvas. Renderer переводит их в мировые координаты и передаёт выбранный гекс в React. Камера и дробное округление пикселей принадлежат renderer.

При размонтировании AbortController отключает ввод. Cleanup отсоединяет наблюдатель размеров и уничтожает приложение PixiJS с canvas и дочерними объектами. Если инициализация завершилась уже после размонтирования, созданное приложение сразу освобождается. Ошибки загрузки ядра и открытия WebGL выводятся в панели состояния.

`game-ai` зарезервирован для потребителя публичного API ядра на T-012. Игровой API WASM и рендер карты сценария запланированы отдельно на T-009 и T-010.
