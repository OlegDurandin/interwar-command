## Проверки

Windows ARM64, MSVC и Windows SDK, Rust 1.100.0, wasm-pack 0.13.1, Node 22.16.0, pnpm 10.11.1. Браузер — Chromium 140.0.7339.186 из Playwright 1.55.1. Команды указаны относительно корня. Составные команды запускали вложенные проверки.

| Команда | Результат | Наблюдение |
|---|---|---|
| `pnpm install`, `pnpm install --frozen-lockfile` | pass | Созданы и проверены зависимости обоих пакетов workspace |
| `cargo fmt --all --check` | pass | Форматирование workspace |
| `cargo test --workspace` | pass | 3 теста Hex, включая порядок, симметрию, отрицательные и крайние координаты |
| `cargo clippy --workspace --all-targets -- -D warnings` | pass | Код возврата 0. Отдельное сообщение Cargo об объявленной зависимости пустого game-ai от game-core |
| `pnpm wasm:build` | pass | wasm-pack создал бинарный модуль, ES-модуль и объявления в crates/game-wasm/pkg |
| `pnpm lint`, `pnpm typecheck` | pass | ESLint и tsc со strict, сгенерированная сигнатура hex_distance возвращает bigint |
| `pnpm test` | pass | Rust workspace и 3 теста Vitest, в том числе обе стороны наклонного ребра и picking после преобразования камеры |
| `pnpm build` | pass | Vite выпустил HTML, CSS, JS и отдельный .wasm в apps/web/dist |
| `pnpm test:e2e` | pass | 2 теста Chromium на production preview. Проверены бинарный заголовок WASM, выделение и расстояния 5, 9, 8, drag, zoom, resize, отсутствие ошибок и явная ошибка при блокировке WASM |
| `pnpm dev` | pass | Автосборка WASM, запуск Vite; интерактивный браузерный smoke с React StrictMode |
| `pnpm check` | pass | Совокупный запуск обязательных проверок первого этапа |

Проверка локальной копии началась без каталога `pkg`. JS-зависимости установлены по pnpm-lock.yaml, пакет WASM собран из Rust. На общем диске VirtualBox отдельно потребовались явный путь workspace, режим установки `hoisted` и polling для Vite. После этой настройки `pnpm check` и браузерная проверка `pnpm dev` прошли непосредственно на `Y:`. Команды PowerShell для этой среды приведены в [README.md](README.md).
